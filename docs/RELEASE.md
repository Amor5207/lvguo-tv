# 绿果TV 1.0.0

面向 Android 电视与投影仪的个人自用短剧客户端，支持遥控器操作和局域网手机遥控。

- 推荐、搜索、分类筛选、选季选集与评论。
- 手机扫码或输入链接即可连接，支持多人同时控制。
- 本地历史、追剧、断点续播和已看完追剧清理。
- 按设备能力选择画质，兼容尝试失败后回退至 720P。

## 下载

下载 Release 附件 `hongguo-tv.apk`，安装到电视或投影仪。手机使用浏览器访问电视显示的链接，无需另装应用。

- 版本：`1.0.0`，内部版本号 `20`。

## 设备与维护

作者尝试设备：京东京造北极星 Lite 投影仪（Android 9）。其他设备需自行测试，画质取决于实际解码能力。

个人自用，仅修复影响作者本人使用的 BUG。不受理其他设备的 BUG、兼容性问题，也不接受样式和布局类优化建议。有其他需求请自行 Fork、Vibe Coding。
