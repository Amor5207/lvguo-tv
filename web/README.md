# 绿果TV · 网页版

沿用电视版的绿色与圆角语言、为电脑重新设计的网页版，Go 编写的单个二进制：

| 产物 | 说明 |
| --- | --- |
| `lvguo-linux-amd64` | 网页版服务端：电脑浏览器打开 PC 界面，手机浏览器给出友好提示 |

- **PC 界面**（iOS / iPadOS 语言，专为桌面设计，配色与 TV 版一致）：悬浮毛玻璃侧栏（搜索 `/`、导航、账号、主题）；每页都是「大标题 → 分组圆角卡片」，滚动时大标题折叠进渐进模糊的顶栏；首页精选轮播与继续观看书架，榜单为领奖台加双列榜单，分类为分组筛选卡，详情页随封面取色的大图头部加双栏。
- **加载体验**：骨架屏与真实布局同结构（加载前后不跳动）；图片真懒加载（进视口前不请求），先出模糊缩略图再渐进清晰；无限滚动以骨架行预告；接口短时缓存与悬停预取详情。
- **播放器**：影院式布局，视频居中，右侧停靠选集与评论面板；悬浮毛玻璃控制条，弹幕、倍速、清晰度、自动连播；快捷键 空格 / ← → / ↑ ↓ / N / P / F / M / D / T。
- **手机浏览器**：不支持（登录需要手机红果 App 扫码，手机无法扫自己屏幕），访问时给出友好提示，引导到电脑上打开。
- **不强制登录**：浏览、搜索、播放都可以匿名使用，登录后才同步收藏、历史与进度。
- 账号：红果 App 扫码登录；收藏、观看历史、播放进度与手机红果 App 实时同步（开始播放上报一次，之后约每 5 秒一次，暂停、切集、关闭时再各上报一次）。
- 视频：服务端下载并解密 CENC，浏览器用硬件解码播放 H.265。
- 多用户：每个浏览器是独立会话，登录凭证只保存在服务端，不互相可见。

## 构建

```shell
cd web
go test ./...
# 网页版服务端
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -trimpath -ldflags="-s -w -X main.version=2.0.0" -o dist/lvguo-linux-amd64 ./cmd/lvguo
```

只用标准库，无第三方依赖；界面是纯 HTML / CSS / JS，打进二进制，无需前端构建。

## 运行与部署

```shell
./lvguo-linux-amd64 -addr 127.0.0.1:8780 -data /var/lib/lvguo-tv-data
```

放在 nginx / CDN 后面即可（需透传 `X-Forwarded-For`、`X-Forwarded-Proto`，`/media/` 关闭缓冲）。`GET /healthz` 返回 `lvguo-tv`。

## 目录

```
cmd/lvguo/        入口与服务启动
internal/sign/    请求签名（与 Android 端 Signer.java 逐字节对拍的测试）
internal/hg/      红果接口：设备注册、内容、账号、扫码登录
internal/cenc/    spade 密钥还原与 CENC MP4 解密
internal/server/  HTTP 服务：会话、接口、视频流、页面切换
ui/               PC / 手机 / 共享前端
```

## 说明

本程序与红果短剧及其关联公司无关，不存储、不分发任何视频；视频仅在内存中解密后流式提供给当前用户。
